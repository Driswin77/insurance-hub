## Overview

Insurance Hub is a modern web application that provides users with information about various insurance plans, including Life, Health, and Motor Insurance. It also allows users to submit enquiry requests through an interactive form.

---

## Features

- Browse insurance plans
- Life, Health, and Motor Insurance sections
- Responsive user interface
- Enquiry form for customer requests
- Simple and intuitive navigation

---

## Tech Stack

- React 19
- Vite
- Material UI
- React Router DOM
